Репозиторий содержит коллекцию инструментов,
предназначенных для автоматизации задач администрирования операционной системы Windows,
с фокусом на работу с системным реестром, стандартными файлами и групповыми политиками.

Проект разработан в результате эволюции подхода к управлению конфигурацией:
от набора изолированных файлов для точечных изменений — к интегрированной системе,
обеспечивающей централизованный контроль,
повторяемость операций и снижение операционных и трансакционных издержек.
